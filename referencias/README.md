# referencias

Material de origem que o jogo **não** carrega: fotos e arte-fonte que a equipe
de design usou, ou vai usar, para desenhar os cenários.

Esta pasta fica fora do sistema de recursos do GDevelop de propósito. Nada aqui
é declarado como recurso, então nada aqui entra no build nem pesa no download
do aluno. O validador ignora a pasta.

O que está aqui veio de recursos que estavam declarados sem uso e pesavam no
export sem aparecer em cena nenhuma. São grandes demais para serem sprites —
são fotografia e arte de referência.

Serve principalmente ao trabalho de reautorar os fundos na grade de pixel art
definida em `docs/01-DIAGNOSTICO.md` (480x270, tiles de 16x16): fotografia
reduzida não vira pixel art, mas é a referência a partir da qual o pixel art é
desenhado.

Ao reautorar um fundo, o arquivo novo vai para `assets/`, declarado como
recurso. O original fica aqui.
